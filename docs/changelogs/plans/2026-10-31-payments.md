# Payments Module Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `Payments` module that owns payment intents and refunds, integrates Stripe and PayPal behind one port, accepts signed webhooks, and exposes customer/admin/webhook HTTP surfaces using the existing `Result` contract.

**Architecture:** `Payment` is an event-sourced aggregate (`Core`) with guarded transitions; Application slices are MediatR commands/queries; Infrastructure provides provider adapters and event projections into `payments`, `payment_refunds`, and `payment_webhook_events`. Confirm-return and webhook both call one `SettlePayment` command.

**Tech Stack:** .NET 10, MediatR, FluentValidation, EF Core/PostgreSQL, existing event-sourcing + outbox/inbox stack, Carter, `Stripe.net` 53.0.0 (already referenced), typed `HttpClient` for PayPal, xUnit v3 + AwesomeAssertions + Moq.

**Spec:** `docs/changelogs/specs/2026-10-31-payments-design.md`

## Global Constraints

- Layers: `Core` ← `Application` ← `Infrastructure`; `app/Web.Api` composes. `BuildingBlocks` never references `Modules`.
- Every `/api/*` endpoint returns `Result` / `Result<T>` via `ToApiResult`; status comes from `Result.StatusCode`.
- Statuses: `Pending`, `Processing`, `Authorized`, `Captured`, `PartiallyRefunded`, `Refunded`, `Failed`, `Cancelled`, `Expired`.
- Money is `Money(decimal Amount, Currency Currency)`; API uses `{ "amount": 12.34, "currency": "USD" }`.
- Idempotency: header required on create and refund; same key + same fingerprint returns the original with `Idempotent-Replay: true`; different fingerprint → `409`.
- Provider declines are domain outcomes (`Failed`), never HTTP errors.
- Idempotency keys and provider references are recorded in synchronous side tables, never through projections.
- `Fake` provider must never be enabled in `Production`.
- Comments use the labeled vocabulary (`Validate:`, `Initialize:`, `Enforce:`, `Handle:`, `Fallback:`); no freeform narration.
- File names: no dot, or a recognized role suffix (`.Spec.cs`, `.Test.cs`, `.Interface.cs`, `.Event.cs`, `.Factory.cs`, `.Constant.cs`, `.Validator.cs`, `.Model.cs`, `.Configuration.cs`, `.Composition.cs`).
- `net10.0`, nullable enabled, warnings as errors, Central Package Management (no `Version` on `PackageReference`).
- CI: `make lint`, `make build`, `make test`, coverage 90% line / 80% branch, `make structure.check`.

```csharp
            id: Guid.NewGuid(),
            provider: PaymentProvider.Fake,
            providerReference: "fake_ref_1",
            amount: Usd(49.90m),
            captureMode: mode,
            externalReference: "cart-1",
            idempotencyKey: "key-1",

            customerId: Guid.NewGuid(),
```

```csharp
using Core.BuildingBlocks.Functional.Results;

namespace Core.Modules.Payments.Intents;

/// <summary>Validates payment invariants that do not depend on provider I/O.</summary>
public static class PaymentValidator
{
    /// <summary>Validates a newly initiated payment.</summary>
    /// <param name="payment">Candidate payment.</param>
    /// <returns>Success, or the first broken invariant.</returns>
    public static Result ValidateInitiation(Payment payment)
    {
        ArgumentNullException.ThrowIfNull(payment);

        return Result.Ok()
            .Ensure(_ => payment.Amount.Amount > 0
                ? Result.Ok()
                : Result.Fail(PaymentsOutcome.Failure.AmountInvalid("must be greater than zero")))
            .Ensure(_ => !string.IsNullOrWhiteSpace(payment.ExternalReference)
                ? Result.Ok()
                : Result.Fail(PaymentsOutcome.Failure.ReferenceRequired("external reference")))
            .Ensure(_ => payment.ExternalReference.Length <= PaymentConstant.Constraints.ReferenceMaxLength
                ? Result.Ok()
                : Result.Fail(PaymentsOutcome.Failure.AmountInvalid("external reference is too long")))
            .Ensure(_ => !string.IsNullOrWhiteSpace(payment.IdempotencyKey)
                ? Result.Ok()
                : Result.Fail(PaymentsOutcome.Failure.ReferenceRequired("idempotency key")))
            .Ensure(_ => payment.IdempotencyKey.Length <= PaymentConstant.Constraints.IdempotencyKeyMaxLength
                ? Result.Ok()
                : Result.Fail(PaymentsOutcome.Failure.AmountInvalid("idempotency key is too long")));
    }
```

```csharp
using Core.BuildingBlocks.Domain.Events;
using Core.BuildingBlocks.Domain.EventSourcing;
using Core.BuildingBlocks.Domain.ValueObjects.Money;
using Core.Modules.Payments.Refunds;

namespace Core.Modules.Payments.Intents;

/// <summary>An event-sourced payment intent and its capture/refund state.</summary>
public sealed class Payment : EventSourcedAggregate<Guid>
{
    private readonly List<Refund> _refunds = [];

    internal Payment() { }

    /// <summary>The provider that settles this payment.</summary>
    public PaymentProvider Provider { get; private set; }

    /// <summary>The provider-side intent or order identifier.</summary>
    public string? ProviderReference { get; private set; }

    /// <summary>The immutable requested amount.</summary>
    public Money Amount { get; private set; }

    /// <summary>Automatic or manual capture.</summary>
    public PaymentCaptureMode CaptureMode { get; private set; }

    /// <summary>The caller's cart or order key.</summary>
    public string ExternalReference { get; private set; } = string.Empty;

    /// <summary>The caller's idempotency key.</summary>
    public string IdempotencyKey { get; private set; } = string.Empty;

    /// <summary>The fingerprint of the request that created the payment.</summary>
    public string IdempotencyFingerprint { get; private set; } = string.Empty;

    /// <summary>The owning customer.</summary>
    public Guid CustomerId { get; private set; }

    /// <summary>The current lifecycle state.</summary>
    public PaymentStatus Status { get; private set; }

    /// <summary>Funds held by the provider.</summary>
    public Money AuthorizedAmount { get; private set; }

    /// <summary>Funds captured so far.</summary>
    public Money CapturedAmount { get; private set; }

    /// <summary>Funds refunded so far.</summary>
    public Money RefundedAmount { get; private set; }

    /// <summary>The provider failure code, when failed.</summary>
    public string? FailureCode { get; private set; }

    /// <summary>The provider-safe failure message.</summary>
    public string? FailureMessage { get; private set; }

    /// <summary>The hosted-checkout redirect target while the customer must act.</summary>
    public string? ApprovalUrl { get; private set; }

    /// <summary>When the intent stops being payable.</summary>
    public DateTimeOffset? ExpiresAt { get; private set; }

    /// <summary>When the payment was created.</summary>
    public DateTimeOffset CreatedAt { get; private set; }

    /// <summary>When the payment last changed.</summary>
    public DateTimeOffset UpdatedAt { get; private set; }

    /// <summary>The refunds issued against this payment.</summary>
    public IReadOnlyList<Refund> Refunds => _refunds;

    /// <summary>The remaining amount that can still be refunded.</summary>
    public decimal CreditAllowed => CapturedAmount.Amount - RefundedAmount.Amount;

    /// <summary>The remaining amount that can still be captured.</summary>
    public decimal RemainingCapturable => Math.Max(0m, Amount.Amount - CapturedAmount.Amount);

    /// <summary>Whether the payment can accept a capture right now.</summary>
    public bool CanCapture => Status is PaymentStatus.Pending
        or PaymentStatus.Processing
        or PaymentStatus.Authorized
        or PaymentStatus.Expired
        or PaymentStatus.Failed;

    /// <summary>Whether the payment can accept a refund right now.</summary>
    public bool CanRefund => Status is PaymentStatus.Captured or PaymentStatus.PartiallyRefunded
        && CreditAllowed > 0;

    /// <summary>Applies a provider observation using the aggregate's transition rules.</summary>
    public Result<Payment> ApplyObservation(
        PaymentObservation observation,
        string providerReference,
        Money? amount,
        string? failureCode,
        DateTimeOffset nowUtc) => observation switch
    {
        PaymentObservation.Authorized => Authorize(providerReference, amount ?? Amount, nowUtc),
        PaymentObservation.Captured => Capture(amount ?? Amount, providerReference, nowUtc),
        PaymentObservation.Failed => Fail(failureCode ?? PaymentConstant.Reasons.ProviderFailed, null, nowUtc),
        PaymentObservation.Cancelled => Cancel(PaymentConstant.Reasons.ProviderCancelled, nowUtc),
        PaymentObservation.Expired => Expire(nowUtc),
        _ => Result<Payment>.Fail(PaymentsOutcome.Failure.InvalidState(Status, "apply the provider observation"))
    };

    /// <summary>Marks the payment as processing.</summary>
    public Result<Payment> MarkProcessing(string? providerReference, DateTimeOffset nowUtc)
    {
        if (Status is not (PaymentStatus.Pending or PaymentStatus.Processing))
            return Result<Payment>.Fail(PaymentsOutcome.Failure.InvalidState(Status, "start processing"));

        return RaiseEvent(new PaymentProcessing(Id, providerReference, nowUtc));
    }

    /// <summary>Records an authorization for manual capture.</summary>
    public Result<Payment> Authorize(string providerReference, Money authorized, DateTimeOffset nowUtc)
    {
        if (CaptureMode is not PaymentCaptureMode.Manual)
            return Result<Payment>.Fail(PaymentsOutcome.Failure.InvalidState(Status, "authorize"));

        if (Status is not (PaymentStatus.Pending or PaymentStatus.Processing))
            return Result<Payment>.Fail(PaymentsOutcome.Failure.InvalidState(Status, "authorize"));

        if (authorized.Amount <= 0 || authorized.Amount > Amount.Amount)
            return Result<Payment>.Fail(PaymentsOutcome.Failure.AmountInvalid("authorized amount is out of range"));

        if (authorized.Currency != Amount.Currency)
            return Result<Payment>.Fail(PaymentsOutcome.Failure.CurrencyMismatch(
                Amount.Currency.Code ?? string.Empty, authorized.Currency.Code ?? string.Empty));

        return RaiseEvent(new PaymentAuthorized(Id, providerReference, authorized, nowUtc));
    }

    /// <summary>Captures part or all of the payment.</summary>
    public Result<Payment> Capture(Money captured, string providerReference, DateTimeOffset nowUtc)
    {
        if (!CanCapture)
            return Result<Payment>.Fail(PaymentsOutcome.Failure.InvalidState(Status, "capture"));

        bool lateSettlement = Status is PaymentStatus.Expired or PaymentStatus.Failed;

        if (CaptureMode is PaymentCaptureMode.Manual && Status is not PaymentStatus.Authorized && !lateSettlement)
            return Result<Payment>.Fail(PaymentsOutcome.Failure.InvalidState(Status, "capture before authorization"));

        if (string.IsNullOrWhiteSpace(providerReference))
            return Result<Payment>.Fail(PaymentsOutcome.Failure.ProviderReferenceMissing());

        if (captured.Amount <= 0)
            return Result<Payment>.Fail(PaymentsOutcome.Failure.AmountInvalid("captured amount must be positive"));

        if (captured.Currency != Amount.Currency)
            return Result<Payment>.Fail(PaymentsOutcome.Failure.CurrencyMismatch(
                Amount.Currency.Code ?? string.Empty, captured.Currency.Code ?? string.Empty));

        if (captured.Amount > RemainingCapturable)
            return Result<Payment>.Fail(PaymentsOutcome.Failure.AmountInvalid(
                "captured amount exceeds the remaining amount"));

        string reason = Status switch
        {
            PaymentStatus.Expired => PaymentConstant.Defaults.LateSettlement,
            PaymentStatus.Failed => PaymentConstant.Defaults.SettledAfterFailure,
            _ => PaymentConstant.Defaults.InitialCapture
        };

        return RaiseEvent(new PaymentCaptured(
            Id,
            providerReference,
            captured,
            new Money(CapturedAmount.Amount + captured.Amount, Amount.Currency),
            reason,
            nowUtc));
    }

    /// <summary>Records a rejected capture without moving the payment.</summary>
    public Result<Payment> CaptureFailed(Money attempted, string code, string? message, DateTimeOffset nowUtc)
    {
        if (Status is not PaymentStatus.Authorized)
            return Result<Payment>.Fail(PaymentsOutcome.Failure.InvalidState(Status, "record a capture failure"));

        return RaiseEvent(new PaymentCaptureFailed(Id, attempted, code, message, nowUtc));
    }

    /// <summary>Marks the payment failed.</summary>
    public Result<Payment> Fail(string code, string? message, DateTimeOffset nowUtc)
    {
        if (Status is not (PaymentStatus.Pending or PaymentStatus.Processing))
            return Result<Payment>.Fail(PaymentsOutcome.Failure.InvalidState(Status, "fail"));

        return RaiseEvent(new PaymentFailed(Id, code, message, nowUtc));
    }

    /// <summary>Voids the payment before any capture.</summary>
    public Result<Payment> Cancel(string reason, DateTimeOffset nowUtc)
    {
        if (Status is not (PaymentStatus.Pending or PaymentStatus.Processing or PaymentStatus.Authorized))
            return Result<Payment>.Fail(PaymentsOutcome.Failure.InvalidState(Status, "cancel"));

        if (CapturedAmount.Amount > 0)
            return Result<Payment>.Fail(PaymentsOutcome.Failure.InvalidState(Status, "cancel captured funds"));

        return RaiseEvent(new PaymentCancelled(Id, reason, nowUtc));
    }

    /// <summary>Expires an unpaid intent.</summary>
    public Result<Payment> Expire(DateTimeOffset nowUtc)
    {
        if (Status is not PaymentStatus.Pending)
            return Result<Payment>.Fail(PaymentsOutcome.Failure.InvalidState(Status, "expire"));

        return RaiseEvent(new PaymentExpired(Id, nowUtc));
    }

    /// <inheritdoc />
    protected override void When(IDomainEvent domainEvent)
    {
        switch (domainEvent)
        {
            case PaymentInitiated initiated:
                Id = initiated.PaymentId;
                Provider = initiated.Provider;
                ProviderReference = initiated.ProviderReference;
                Amount = initiated.Amount;
                CaptureMode = initiated.CaptureMode;
                ExternalReference = initiated.ExternalReference;
                IdempotencyKey = initiated.IdempotencyKey;
                IdempotencyFingerprint = initiated.IdempotencyFingerprint;
                CustomerId = initiated.CustomerId;
                ApprovalUrl = initiated.ApprovalUrl;
                ExpiresAt = initiated.ExpiresAt;
                CreatedAt = initiated.CreatedAtUtc;
                UpdatedAt = initiated.CreatedAtUtc;
                Status = PaymentStatus.Pending;
                AuthorizedAmount = new Money(0, initiated.Amount.Currency);
                CapturedAmount = new Money(0, initiated.Amount.Currency);
                RefundedAmount = new Money(0, initiated.Amount.Currency);
                break;

            case PaymentProcessing processing:
                ProviderReference ??= processing.ProviderReference;
                Status = PaymentStatus.Processing;
                UpdatedAt = processing.OccurredAtUtc;
                break;

            case PaymentAuthorized authorized:
                ProviderReference = authorized.ProviderReference;
                AuthorizedAmount = authorized.AuthorizedAmount;
                Status = PaymentStatus.Authorized;
                UpdatedAt = authorized.OccurredAtUtc;
                break;

            case PaymentCaptured captured:
                ProviderReference = captured.ProviderReference;
                CapturedAmount = captured.TotalCapturedAmount;
                AuthorizedAmount = captured.TotalCapturedAmount;
                Status = RefundedAmount.Amount > 0
                    ? (CapturedAmount.Amount > RefundedAmount.Amount ? PaymentStatus.PartiallyRefunded : PaymentStatus.Refunded)
                    : PaymentStatus.Captured;
                ApprovalUrl = null;
                UpdatedAt = captured.OccurredAtUtc;
                break;

            case PaymentCaptureFailed captureFailed:
                FailureCode = captureFailed.FailureCode;
                FailureMessage = captureFailed.FailureMessage;
                UpdatedAt = captureFailed.OccurredAtUtc;
                break;

            case PaymentFailed failed:
                FailureCode = failed.FailureCode;
                FailureMessage = failed.FailureMessage;
                Status = PaymentStatus.Failed;
                ApprovalUrl = null;
                UpdatedAt = failed.OccurredAtUtc;
                break;

            case PaymentCancelled cancelled:
                Status = PaymentStatus.Cancelled;
                ApprovalUrl = null;
                UpdatedAt = cancelled.OccurredAtUtc;
                break;

            case PaymentExpired expired:
                Status = PaymentStatus.Expired;
                ApprovalUrl = null;
                UpdatedAt = expired.ExpiredAtUtc;
                break;

            case RefundRequested requested:
                _refunds.Add(Refund.Request(requested));
                UpdatedAt = requested.OccurredAtUtc;
                break;

            case RefundSucceeded succeeded:
                ApplyRefundSucceeded(succeeded);
                break;

            case RefundFailed failed:
                Refund? refund = _refunds.FirstOrDefault(item => item.Id == failed.RefundId);
                refund?.MarkFailed(failed.FailureCode, failed.FailureMessage);
                UpdatedAt = failed.OccurredAtUtc;
                break;
        }
    }

    private void ApplyRefundSucceeded(RefundSucceeded succeeded)
    {
        Refund? refund = _refunds.FirstOrDefault(item => item.Id == succeeded.RefundId);
        refund?.MarkSucceeded(succeeded.ProviderReference);
        RefundedAmount = new Money(RefundedAmount.Amount + succeeded.Amount.Amount, Amount.Currency);
        Status = CapturedAmount.Amount > RefundedAmount.Amount
            ? PaymentStatus.PartiallyRefunded
            : PaymentStatus.Refunded;
        UpdatedAt = succeeded.OccurredAtUtc;
    }
}
```

```csharp
using Core.BuildingBlocks.Domain.ValueObjects.Money;

namespace Core.Modules.Payments.Intents;

/// <summary>Refund transitions on the payment aggregate.</summary>
public static class PaymentRefundExtension
{
    /// <summary>Requests a refund and validates the captured remainder.</summary>
    public static Result<Payment> RequestRefund(
        this Payment payment,
        Guid refundId,
        Money amount,
        string reason,
        string idempotencyKey,
        DateTimeOffset nowUtc)
    {
        ArgumentNullException.ThrowIfNull(payment);

        if (payment.Status is not (PaymentStatus.Captured or PaymentStatus.PartiallyRefunded))
            return Result<Payment>.Fail(PaymentsOutcome.Failure.RefundNotCaptured(payment.Status));

        if (payment.Refunds.Any(refund => refund.Id == refundId))
            return Result<Payment>.Success(payment);

        if (amount.Amount <= 0 || amount.Currency != payment.Amount.Currency)
            return Result<Payment>.Fail(PaymentsOutcome.Failure.AmountInvalid("refund amount is out of range"));

        if (amount.Amount > payment.CreditAllowed)
            return Result<Payment>.Fail(
                PaymentsOutcome.Failure.RefundExceedsCredit(amount.Amount, payment.CreditAllowed));

        return payment.RaiseEvent(new RefundRequested(
            refundId, payment.Id, amount, reason, idempotencyKey, nowUtc));
    }

    /// <summary>Confirms a refund and advances the payment totals.</summary>
    public static Result<Payment> CompleteRefund(
        this Payment payment,
        Guid refundId,
        string providerReference,
        DateTimeOffset nowUtc)
    {
        ArgumentNullException.ThrowIfNull(payment);

        Refund? refund = payment.Refunds.FirstOrDefault(item => item.Id == refundId);
        if (refund is null)
            return Result<Payment>.Fail(PaymentsOutcome.Failure.RefundNotFound(refundId));

        if (refund.Status is RefundStatus.Succeeded)
            return Result<Payment>.Success(payment);

        return payment.RaiseEvent(new RefundSucceeded(
            refundId, payment.Id, refund.Amount, providerReference, nowUtc));
    }

    /// <summary>Records a rejected refund.</summary>
    public static Result<Payment> FailRefund(
        this Payment payment,
        Guid refundId,
        string failureCode,
        string? failureMessage,
        DateTimeOffset nowUtc)
    {
        ArgumentNullException.ThrowIfNull(payment);

        return payment.RaiseEvent(new RefundFailed(
            refundId, payment.Id, failureCode, failureMessage, nowUtc));
    }
}
```

```csharp
using System.Security.Cryptography;
using System.Text;
using System.Text.Json;

using Application.Modules.Payments.Ports;
using Application.Modules.Payments.Ports.Models;

using Core.BuildingBlocks.Functional.Maybes;
using Core.Modules.Payments;
using Core.Modules.Payments.Intents;

namespace Infrastructure.Modules.Payments.Adapters.Fake;

/// <summary>Deterministic in-memory gateway for development and tests.</summary>
public sealed class FakePaymentGateway : IPaymentGateway, ISupportsPartialRefund, ISupportsManualCapture
{
    /// <summary>The shared secret used by the fake signature scheme.</summary>
    public const string WebhookSecret = "fake-webhook-secret";

    /// <summary>The failure code reported for scripted declines.</summary>
    public const string DeclinedCode = "fake_declined";

    /// <summary>The prefix of the fake HMAC signature.</summary>
    public const string SignaturePrefix = "sha256=";

    /// <inheritdoc />
    public PaymentProvider Provider => PaymentProvider.Fake;

    /// <inheritdoc />
    public Task<Result<PaymentIntentResult>> CreateIntentAsync(
        PaymentIntentRequest request,
        CancellationToken cancellationToken)
    {
        ArgumentNullException.ThrowIfNull(request);

        string reference = $"fake_{request.PaymentId:N}";

        if (request.ExternalReference.StartsWith("decline:", StringComparison.Ordinal))
            return Task.FromResult(Result<PaymentIntentResult>.Success(new PaymentIntentResult(
                reference, PaymentProviderIntentStatus.Failed, null, null, null, FakePaymentGateway.DeclinedCode)));

        if (request.ExternalReference.StartsWith("timeout:", StringComparison.Ordinal))
            return Task.FromResult(Result<PaymentIntentResult>.Fail(
                PaymentsOutcome.Failure.ProviderUnavailable(PaymentProvider.Fake)));

        PaymentProviderIntentStatus status = request.ExternalReference.StartsWith("declined-async:", StringComparison.Ordinal)
            ? PaymentProviderIntentStatus.Processing
            : PaymentProviderIntentStatus.RequiresAction;

        return Task.FromResult(Result<PaymentIntentResult>.Success(new PaymentIntentResult(
            reference,
            status,
            $"https://fake.pay/{reference}",
            "fake_client_secret",
            DateTimeOffset.UtcNow.AddMinutes(30),
            null)));
    }

    /// <inheritdoc />
    public Task<Result<PaymentIntentResult>> RetrieveAsync(string providerReference, CancellationToken cancellationToken)
        => Task.FromResult(Result<PaymentIntentResult>.Success(new PaymentIntentResult(
            providerReference, PaymentProviderIntentStatus.Captured, null, null, null, null)));

    /// <inheritdoc />
    public Task<Result<PaymentCaptureResult>> CaptureAsync(
        PaymentCaptureRequest request,
        CancellationToken cancellationToken)
        => Task.FromResult(Result<PaymentCaptureResult>.Success(
            new PaymentCaptureResult($"cap_{request.IdempotencyKey}", request.Amount, true, null)));

    /// <inheritdoc />
    public Task<Result<PaymentCancelResult>> CancelAsync(
        PaymentCancelRequest request,
        CancellationToken cancellationToken)
        => Task.FromResult(Result<PaymentCancelResult>.Success(new PaymentCancelResult(true, null)));

    /// <inheritdoc />
    public Task<Result<PaymentRefundResult>> RefundAsync(
        PaymentRefundRequest request,
        CancellationToken cancellationToken)
        => Task.FromResult(Result<PaymentRefundResult>.Success(
            new PaymentRefundResult($"re_{request.RefundId:N}", request.Amount, true, null)));

    /// <inheritdoc />
    public Task<Result<Maybe<PaymentProviderEvent>>> ParseWebhookAsync(
        string rawBody,
        IReadOnlyDictionary<string, string> headers,
        CancellationToken cancellationToken)
    {
        if (!headers.TryGetValue(PaymentConstant.Headers.FakeSignature, out string? provided)
            || !IsValid(rawBody, provided))
            return Task.FromResult(Result<Maybe<PaymentProviderEvent>>.Fail(
                PaymentsOutcome.Failure.WebhookSignatureInvalid()));

        try
        {
            return Task.FromResult(Parse(rawBody));
        }
        catch (JsonException)
        {
            return Task.FromResult(Result<Maybe<PaymentProviderEvent>>.Fail(
                PaymentsOutcome.Failure.WebhookPayloadInvalid()));
        }
    }

    private static Result<Maybe<PaymentProviderEvent>> Parse(string rawBody)
    {
        using JsonDocument document = JsonDocument.Parse(rawBody);
        JsonElement root = document.RootElement;

        string type = root.GetProperty("type").GetString() ?? string.Empty;
        PaymentProviderEventType? eventType = type switch
        {
            "captured" => PaymentProviderEventType.Captured,
            "authorized" => PaymentProviderEventType.Authorized,
            "failed" => PaymentProviderEventType.Failed,
            "cancelled" => PaymentProviderEventType.Cancelled,
            "expired" => PaymentProviderEventType.Expired,
            "refunded" => PaymentProviderEventType.Refunded,
            "refund_failed" => PaymentProviderEventType.RefundFailed,
            _ => null
        };

        if (eventType is null)
            return Result<Maybe<PaymentProviderEvent>>.Success(Maybe<PaymentProviderEvent>.Empty());

        Money? amount = root.TryGetProperty("amount", out JsonElement amountElement)
            ? new Money(
                amountElement.GetDecimal(),
                new Currency(root.GetProperty("currency").GetString() ?? PaymentConstant.Defaults.Currency))
            : null;

        return Result<Maybe<PaymentProviderEvent>>.Success(Maybe<PaymentProviderEvent>.From(
            new PaymentProviderEvent(
                root.GetProperty("id").GetString()!,
                eventType.Value,
                root.GetProperty("reference").GetString()!,
                root.TryGetProperty("refund", out JsonElement refund) ? refund.GetString() : null,
                amount,
                DateTimeOffset.UtcNow)));
    }

    private static bool IsValid(string rawBody, string? provided)
    {
        if (string.IsNullOrEmpty(provided) || !provided.StartsWith(SignaturePrefix, StringComparison.Ordinal))
            return false;

        string expected = Convert.ToHexStringLower(
            SHA256.HashData(Encoding.UTF8.GetBytes($"{WebhookSecret}:{rawBody}")));

        return CryptographicOperations.FixedTimeEquals(
            Encoding.UTF8.GetBytes(expected),
```

**Final shape (applies over the code blocks below):**

1. `IPaymentPolicy` supplies `MaxAmount`, `IntentLifetime`, and `ExpiryGrace` from configuration; the
   slices must not reference an Infrastructure options type. `CreatePayment` rejects an amount above
   `MaxAmount` with `PaymentsOutcome.Failure.AmountExceedsLimit` before any provider call, and falls back
   to `clock.GetUtcNow() + policy.IntentLifetime` when a provider returns no expiry. `GetPayment` and
   `CancelPayment` apply `policy.ExpiryGrace` before reporting or expiring an overdue intent.
2. Payment slices carry **no** FluentValidation validators. Their 422 responses used property-name codes,
   which violates the documented contract. Validation lives in `PaymentValidator` (initiation, capture,
   refund) and at the endpoint edge, so every rejection is a `PaymentsOutcome` error.
3. Failures come only from `PaymentsOutcome.Failure`; metadata keys and idempotency prefixes come from
   `PaymentConstant.Metadata` / `PaymentConstant.IdempotencyPrefixes`.
4. Provider calls are wrapped in `PaymentMetrics.TrackAsync(provider, operation, call)`, which records the
   `payments.provider.duration` histogram with `provider` and `operation` tags (operation names from
   `PaymentConstant.Operations`).
5. `RefundPayment` gates partial refunds on `gateway.Capabilities.SupportsPartialRefund`.
6. `ProcessPaymentWebhook` belongs to Task 7 and receives `ReadOnlyMemory<byte>`; the slices here do not
   depend on its shape beyond the `SettlePayment` command.

```csharp
                .NotEmpty()
                .MaximumLength(PaymentConstant.Constraints.ReferenceMaxLength);

            RuleFor(command => command.Request.Amount.Amount).GreaterThan(0);
        }
    }

    /// <summary>Handles the command.</summary>
    public sealed class UseCaseHandler(
        IEventSourcedRepository<Payment, Guid> repository,
        IPaymentIdempotencyStore idempotency,
        IPaymentReferenceStore references,
        IPaymentGatewayRegistry registry,
        IUserContext userContext,
        TimeProvider clock) : ICommandHandler<UseCase, Response>
    {
        /// <inheritdoc />
        public async Task<Result<Response>> Handle(UseCase command, CancellationToken cancellationToken)
        {
            ArgumentNullException.ThrowIfNull(command);

            if (!Guid.TryParse(userContext.UserId, out Guid customerId))
                return Result<Response>.Fail(PaymentsOutcome.Failure.CustomerRequired());

            string fingerprint = Fingerprint(command.Request);

            // Enforce: reserve the key synchronously so a replay never creates a second
            // provider intent while the projection is still catching up.
            Result<IdempotencyReservation> reservation = await idempotency.ReserveAsync(
                customerId, command.IdempotencyKey, fingerprint, cancellationToken);

            if (reservation.IsFailure)
                return Result<Response>.Fail(reservation.Errors);

            if (!reservation.Value.IsNew)
            {
                if (!reservation.Value.FingerprintMatches)
                    return Result<Response>.Fail(PaymentsOutcome.Failure.IdempotencyConflict());

                Result<Payment> replay = await repository.LoadAsync(reservation.Value.PaymentId, cancellationToken);
                return replay.IsFailure
                    ? Result<Response>.Fail(replay.Errors)
                    : Result<Response>.Success(replay.Value.ToResponse())
                        .WithMetadata("IdempotentReplay", true);
            }

            Result<Payment> created = await registry.Resolve(command.Request.Provider)
                .BindAsync(
                    (gateway, ct) => CreateWithGatewayAsync(
                        gateway, command.Request, customerId, command.IdempotencyKey,
                        fingerprint, reservation.Value.PaymentId, ct),
                    cancellationToken);

            if (created.IsFailure)
                return Result<Response>.Fail(created.Errors);

            Result saved = await repository.SaveAsync(created.Value, cancellationToken);
            if (saved.IsFailure)
                return Result<Response>.Fail(saved.Errors);

            // Enforce: provider callbacks must resolve before the projection catches up.
            if (created.Value.ProviderReference is not null)
            {
                await references.RecordAsync(
                    created.Value.Provider,
                    created.Value.ProviderReference,
                    created.Value.Id,
                    cancellationToken);
            }

            PaymentMetrics.Initiated.Add(
                1,
                new KeyValuePair<string, object?>("provider", created.Value.Provider.ToString().ToLowerInvariant()));

            return Result<Response>.Success(created.Value.ToResponse())
                .WithStatus(ResultConstant.StatusCode.Created);
        }

        private async Task<Result<Payment>> CreateWithGatewayAsync(
            IPaymentGateway gateway,
            Request request,
            Guid customerId,
            string idempotencyKey,
            string fingerprint,
            Guid id,
            CancellationToken cancellationToken)
        {
            Result<PaymentIntentResult> intent = await gateway.CreateIntentAsync(
                new PaymentIntentRequest(
                    id, request.Amount, gateway.Provider, customerId, request.ExternalReference,
                    request.ReturnUrl, request.CancelUrl, request.CaptureMode, idempotencyKey,
                    new Dictionary<string, string>()),
                cancellationToken);

            if (intent.IsFailure)
                return Result<Payment>.Fail(intent.Errors);

            PaymentIntentResult value = intent.Value;

            return PaymentFactory.Initiate(
                id: id,
                provider: gateway.Provider,
                providerReference: value.ProviderReference,
                amount: request.Amount,
                captureMode: request.CaptureMode,
                externalReference: request.ExternalReference,
                idempotencyKey: idempotencyKey,
                idempotencyFingerprint: fingerprint,
                customerId: customerId,
                approvalUrl: value.ApprovalUrl,
                expiresAt: value.ExpiresAt,
                nowUtc: clock.GetUtcNow())
                .Bind(payment => value.Status is PaymentProviderIntentStatus.Failed
                    ? payment.Fail(value.FailureCode ?? PaymentConstant.Reasons.ProviderFailed, null, clock.GetUtcNow())
                    : Result<Payment>.Success(payment));
        }

        private static string Fingerprint(Request request)
        {
            string raw = string.Join('|',
                request.Provider, request.Amount.Amount.ToString("0.####"),
                request.Amount.Currency.Code, request.ExternalReference,
                request.CaptureMode, request.ReturnUrl, request.CancelUrl);

            return Convert.ToHexStringLower(SHA256.HashData(Encoding.UTF8.GetBytes(raw)));
        }
    }
```

```csharp
        {
            ArgumentNullException.ThrowIfNull(command);

            Guid? paymentId = await references.FindAsync(
                command.Provider, command.ProviderReference, cancellationToken);

            if (paymentId is null)
            {
                PaymentReadModel? row = await store.FindByProviderReferenceAsync(
                    command.Provider, command.ProviderReference, cancellationToken);
                paymentId = row?.Id;
            }

            if (paymentId is null)
                return Result<PaymentResponseModel>.Fail(
                    PaymentsOutcome.Failure.ReferenceNotFound(command.ProviderReference));

                return Result<PaymentResponseModel>.Fail(loaded.Errors);

            DateTimeOffset now = clock.GetUtcNow();

            if (command.Observed is PaymentProviderEventType.Refunded or PaymentProviderEventType.RefundFailed)
                return Result<PaymentResponseModel>.Success(payment.ToResponse());

            PaymentObservation observation = command.Observed switch
            {
                PaymentProviderEventType.Authorized => PaymentObservation.Authorized,
                PaymentProviderEventType.Captured => PaymentObservation.Captured,
                PaymentProviderEventType.Failed => PaymentObservation.Failed,
                PaymentProviderEventType.Cancelled => PaymentObservation.Cancelled,
                PaymentProviderEventType.Expired => PaymentObservation.Expired,
                _ => PaymentObservation.Captured
            };

            Result<Payment> transition = payment.ApplyObservation(
                observation,
                command.ProviderReference,
                command.Amount,
                command.FailureCode,
                now);

            if (transition.IsFailure)
            {
                Error error = transition.Errors[0];
                bool alreadyApplied = error.Code == PaymentsOutcome.Codes.InvalidState
                    && payment.Status is PaymentStatus.Captured or PaymentStatus.Refunded or PaymentStatus.PartiallyRefunded;

                return alreadyApplied
                    ? Result<PaymentResponseModel>.Success(payment.ToResponse())
                    : Result<PaymentResponseModel>.Fail(error);
            }

            Result saved = await repository.SaveAsync(transition.Value, cancellationToken);

            if (saved.IsFailure)
            {
                PaymentMetrics.Failed.Add(1);
                return Result<PaymentResponseModel>.Fail(saved.Errors);
            }

            PaymentMetrics.Settled.Add(1);
            return Result<PaymentResponseModel>.Success(transition.Value.ToResponse());
        }
    }
```

```csharp
                .NotEmpty()

            RuleFor(command => command.Request.Reason)

            if (loaded.IsFailure)
                return Result<Response>.Fail(loaded.Errors);

            Payment payment = loaded.Value;

            Result<IPaymentGateway> resolved = registry.Resolve(payment.Provider);
            if (resolved.IsFailure)
                return Result<Response>.Fail(resolved.Errors);

            IPaymentGateway gateway = resolved.Value;

            if (command.Request.Amount.Amount < payment.CreditAllowed
                && gateway is not ISupportsPartialRefund)
                return Result<Response>.Fail(PaymentsOutcome.Failure.PartialRefundUnsupported());

            Guid refundId = Guid.NewGuid();
            Result<Payment> requested = payment.RequestRefund(
                refundId, command.Request.Amount, command.Request.Reason, command.IdempotencyKey, clock.GetUtcNow());

                    $"refund:{refundId:N}", command.Request.Reason),

                return Result<Response>.Fail(completed.Errors);

            Result saved = await repository.SaveAsync(completed.Value, cancellationToken);
            if (saved.IsFailure)
                return Result<Response>.Fail(saved.Errors);

            Refund refund = completed.Value.Refunds.Single(item => item.Id == refundId);
```

```csharp
        string? externalReference,
        int skip,
        int take,
        CancellationToken cancellationToken)
        => await Filter(customerId, externalReference)

            .Skip(skip)
            .Take(take)
            .ToListAsync(cancellationToken);

        => Filter(customerId, externalReference).CountAsync(cancellationToken);

        PaymentSearchFilter filter,
        PageRequest page,
        CancellationToken cancellationToken)
    {
        IQueryable<PaymentReadModel> query = context.Set<PaymentReadModel>().AsNoTracking();

        if (!string.IsNullOrWhiteSpace(filter.Status))
            query = query.Where(row => row.Status == filter.Status.ToLowerInvariant());

        if (!string.IsNullOrWhiteSpace(filter.Provider))

        if (filter.CreatedTo is not null)
            query = query.Where(row => row.CreatedAt <= filter.CreatedTo);

        int total = await query.CountAsync(cancellationToken);

        List<PaymentReadModel> rows = await query

            .Skip((page.Page - 1) * page.PageSize)
```

```csharp
using Application.Modules.Payments.Persistence;

using Microsoft.EntityFrameworkCore;

namespace Infrastructure.Modules.Payments.Persistence;

/// <summary>Reserves idempotency keys in PostgreSQL.</summary>
public sealed class PaymentIdempotencyStore(DbContext context, TimeProvider clock) : IPaymentIdempotencyStore
{
    /// <inheritdoc />
    public async Task<Result<IdempotencyReservation>> ReserveAsync(
        Guid customerId,
        string idempotencyKey,
        string fingerprint,
        CancellationToken cancellationToken)
    {
        PaymentIdempotencyKey? existing = await FindAsync(customerId, idempotencyKey, cancellationToken);

        if (existing is not null)
            return Result<IdempotencyReservation>.Success(new IdempotencyReservation(
                existing.PaymentId, IsNew: false, FingerprintMatches: existing.Fingerprint == fingerprint));

        Guid paymentId = Guid.NewGuid();

        context.Set<PaymentIdempotencyKey>().Add(new PaymentIdempotencyKey
        {
            Id = Guid.NewGuid(),
            CustomerId = customerId,
            Key = idempotencyKey,
            Fingerprint = fingerprint,
            PaymentId = paymentId,
            CreatedAt = clock.GetUtcNow()
        });

        try
        {
            await context.SaveChangesAsync(cancellationToken);
        }
        catch (DbUpdateException)
        {
            // Fallback: a concurrent request won the unique index; return its reservation.
            PaymentIdempotencyKey? winner = await FindAsync(customerId, idempotencyKey, cancellationToken);
            if (winner is null)
                throw;

            return Result<IdempotencyReservation>.Success(new IdempotencyReservation(
                winner.PaymentId, IsNew: false, FingerprintMatches: winner.Fingerprint == fingerprint));
        }

        return Result<IdempotencyReservation>.Success(
            new IdempotencyReservation(paymentId, IsNew: true, FingerprintMatches: true));
    }

    private Task<PaymentIdempotencyKey?> FindAsync(
        Guid customerId,
        string key,
        CancellationToken cancellationToken)
        => context.Set<PaymentIdempotencyKey>().AsNoTracking()
            .FirstOrDefaultAsync(
                row => row.CustomerId == customerId && row.Key == key,
                cancellationToken);
}
```

```csharp
namespace Infrastructure.Modules.Payments.Persistence;

/// <summary>Reads and writes provider-to-payment mappings.</summary>
public sealed class PaymentReferenceStore(DbContext context, TimeProvider clock) : IPaymentReferenceStore
{
    /// <inheritdoc />
    public async Task<Result> RecordAsync(
        PaymentProvider provider,
        string providerReference,
        Guid paymentId,
        CancellationToken cancellationToken)
    {
        string name = provider.ToString().ToLowerInvariant();

        bool exists = await context.Set<PaymentReference>()
            .AnyAsync(row => row.Provider == name && row.ProviderReference == providerReference, cancellationToken);

        if (exists)
            return Result.Ok();

        context.Set<PaymentReference>().Add(new PaymentReference
        {
            Id = Guid.NewGuid(),
            Provider = name,
            ProviderReference = providerReference,
            PaymentId = paymentId,
            CreatedAt = clock.GetUtcNow()
        });

        try
        {
            await context.SaveChangesAsync(cancellationToken);
        }
        catch (DbUpdateException)
        {
            // Fallback: another request recorded the same reference first; the mapping is identical.
        }

        return Result.Ok();
    }

    /// <inheritdoc />
    public async Task<Guid?> FindAsync(
        PaymentProvider provider,
        string providerReference,
        CancellationToken cancellationToken)
    {
        string name = provider.ToString().ToLowerInvariant();

        return await context.Set<PaymentReference>().AsNoTracking()
            .Where(row => row.Provider == name && row.ProviderReference == providerReference)
            .Select(row => (Guid?)row.PaymentId)
            .FirstOrDefaultAsync(cancellationToken);
    }
}
```

```csharp
using System.Diagnostics.CodeAnalysis;

using Application.BuildingBlocks.EventSourcing;
using Application.BuildingBlocks.Messaging.Serialization;
using Application.Modules.Payments.Intents.Models;
using Application.Modules.Payments.Refunds.Models;

using Core.BuildingBlocks.Domain.Events;
using Core.Modules.Payments.Intents;
using Core.Modules.Payments.Refunds;

using Microsoft.EntityFrameworkCore;

namespace Infrastructure.Modules.Payments.Persistence;

/// <summary>Projects payment events into the payments and refunds tables.</summary>
[ExcludeFromCodeCoverage]
public sealed class PaymentProjection(DbContext context, IDomainEventSerializer serializer) : IProjection
{
    /// <inheritdoc />
    public string Name => "payments";

    /// <inheritdoc />
    public async Task<Result> ApplyAsync(StoredEvent storedEvent, CancellationToken cancellationToken = default)
    {
        IDomainEvent domainEvent = serializer.Deserialize(
            storedEvent.EventName, storedEvent.EventVersion, storedEvent.Payload);

        switch (domainEvent)
        {
            case PaymentInitiated initiated:
                context.Set<PaymentReadModel>().Add(ToRow(initiated, storedEvent.Version));
                break;
            case PaymentProcessing processing:
                await UpdateAsync(processing.PaymentId, row =>
                {
                    row.Status = PaymentStatus.Processing.ToWire();
                    row.UpdatedAt = processing.OccurredAtUtc;
                }, cancellationToken);
                break;
            case PaymentAuthorized authorized:
                await UpdateAsync(authorized.PaymentId, row =>
                {
                    row.ProviderReference = authorized.ProviderReference;
                    row.Status = PaymentStatus.Authorized.ToWire();
                    row.UpdatedAt = authorized.OccurredAtUtc;
                }, cancellationToken);
                break;
            case PaymentCaptured captured:
                await UpdateAsync(captured.PaymentId, row =>
                {
                    row.ProviderReference = captured.ProviderReference;
                    row.CapturedAmount = captured.TotalCapturedAmount.Amount;
                    row.Status = row.RefundedAmount > 0
                        ? (row.CapturedAmount > row.RefundedAmount
                            ? PaymentStatus.PartiallyRefunded.ToWire()
                            : PaymentStatus.Refunded.ToWire())
                        : PaymentStatus.Captured.ToWire();
                    row.ApprovalUrl = null;
                    row.UpdatedAt = captured.OccurredAtUtc;
                }, cancellationToken);
                break;
            case PaymentCaptureFailed captureFailed:
                await UpdateAsync(captureFailed.PaymentId, row =>
                {
                    row.FailureCode = captureFailed.FailureCode;
                    row.FailureMessage = captureFailed.FailureMessage;
                    row.UpdatedAt = captureFailed.OccurredAtUtc;
                }, cancellationToken);
                break;
            case PaymentFailed failed:
                await UpdateAsync(failed.PaymentId, row =>
                {
                    row.Status = PaymentStatus.Failed.ToWire();
                    row.FailureCode = failed.FailureCode;
                    row.FailureMessage = failed.FailureMessage;
                    row.ApprovalUrl = null;
                    row.UpdatedAt = failed.OccurredAtUtc;
                }, cancellationToken);
                break;
            case PaymentCancelled cancelled:
                await UpdateAsync(cancelled.PaymentId, row =>
                {
                    row.Status = PaymentStatus.Cancelled.ToWire();
                    row.ApprovalUrl = null;
                    row.UpdatedAt = cancelled.OccurredAtUtc;
                }, cancellationToken);
                break;
            case PaymentExpired expired:
                await UpdateAsync(expired.PaymentId, row =>
                {
                    row.Status = PaymentStatus.Expired.ToWire();
                    row.ApprovalUrl = null;
                    row.UpdatedAt = expired.ExpiredAtUtc;
                }, cancellationToken);
                break;
            case RefundRequested requested:
                context.Set<RefundReadModel>().Add(new RefundReadModel
                {
                    Id = requested.RefundId,
                    PaymentId = requested.PaymentId,
                    Status = RefundStatus.Pending.ToWire(),
                    Amount = requested.Amount.Amount,
                    Currency = requested.Amount.Currency.Code ?? PaymentConstant.Defaults.Currency,
                    Reason = requested.Reason,
                    IdempotencyKey = requested.IdempotencyKey,
                    CreatedAt = requested.OccurredAtUtc,
                    UpdatedAt = requested.OccurredAtUtc
                });
                break;
            case RefundSucceeded succeeded:
                await UpdateRefundAsync(succeeded.RefundId, refund =>
                {
                    refund.Status = RefundStatus.Succeeded.ToWire();
                    refund.ProviderReference = succeeded.ProviderReference;
                    refund.UpdatedAt = succeeded.OccurredAtUtc;
                }, cancellationToken);
                await UpdateAsync(succeeded.PaymentId, row =>
                {
                    row.RefundedAmount += succeeded.Amount.Amount;
                    row.Status = row.CapturedAmount > row.RefundedAmount
                        ? PaymentStatus.PartiallyRefunded.ToWire()
                        : PaymentStatus.Refunded.ToWire();
                    row.UpdatedAt = succeeded.OccurredAtUtc;
                }, cancellationToken);
                break;
            case RefundFailed failed:
                await UpdateRefundAsync(failed.RefundId, refund =>
                {
                    refund.Status = RefundStatus.Failed.ToWire();
                    refund.FailureCode = failed.FailureCode;
                    refund.FailureMessage = failed.FailureMessage;
                    refund.UpdatedAt = failed.OccurredAtUtc;
                }, cancellationToken);
                break;
        }

        await context.SaveChangesAsync(cancellationToken);
        return Result.Ok();
    }

    private static PaymentReadModel ToRow(PaymentInitiated initiated, long version) => new()
    {
        Id = initiated.PaymentId,
        Provider = initiated.Provider.ToString().ToLowerInvariant(),
        ProviderReference = initiated.ProviderReference,
        Status = PaymentStatus.Pending.ToWire(),
        Amount = initiated.Amount.Amount,
        Currency = initiated.Amount.Currency.Code ?? PaymentConstant.Defaults.Currency,
        ExternalReference = initiated.ExternalReference,
        IdempotencyKey = initiated.IdempotencyKey,
        IdempotencyFingerprint = initiated.IdempotencyFingerprint,
        CustomerId = initiated.CustomerId,
        ApprovalUrl = initiated.ApprovalUrl,
        ExpiresAt = initiated.ExpiresAt,
        CreatedAt = initiated.CreatedAtUtc,
        UpdatedAt = initiated.CreatedAtUtc,
        Version = (int)version
    };

    private async Task UpdateAsync(Guid id, Action<PaymentReadModel> change, CancellationToken cancellationToken)
    {
        PaymentReadModel? row = await context.Set<PaymentReadModel>().FindAsync([id], cancellationToken);
        if (row is not null)
            change(row);
    }

    private async Task UpdateRefundAsync(Guid id, Action<RefundReadModel> change, CancellationToken cancellationToken)
    {
        RefundReadModel? row = await context.Set<RefundReadModel>().FindAsync([id], cancellationToken);
        if (row is not null)
            change(row);
    }
}
```

**Final shape (applies over the code blocks above):**

1. `IPaymentReadStore` and `IPaymentReferenceStore.FindAsync` are **monadic**: they return
   `Result<T>`, and an absent row is `PaymentsOutcome.Failure.NotFound` / `ReferenceNotFound`, never
   `null`. `make convention.check` enforces this for `*.Interface.cs`.

   range, so operators can slice by the per-currency policy.
3. `payment_webhook_events` keeps UTC `DateTime` timestamps (orderable on every provider) and gains
   `DeleteProcessedBeforeAsync`, used by the retention worker; only processed rows are pruned.
4. Projection timestamps are UTC `DateTime` for the same reason; mapping converts to `DateTimeOffset`
   at the API boundary.
5. The migration is a single `AddPayments` created from the pre-payments snapshot, so it carries
   `EnsureSchema("payment")` and all five tables.

```csharp
using Application.BuildingBlocks.EventSourcing;
using Application.Modules.Payments.Intents.Commands;
using Application.Modules.Payments.Intents.Models;
using Application.Modules.Payments.Persistence;
using Application.Modules.Payments.Ports;
using Application.Modules.Payments.Ports.Models;

using Core.BuildingBlocks.Functional.Maybes;
using Core.BuildingBlocks.Domain.ValueObjects.Money;
using Core.Modules.Payments;
using Core.Modules.Payments.Intents;

using FluentValidation;

using MediatR;

namespace Application.Modules.Payments.Webhooks.Commands;

/// <summary>Verifies, deduplicates, and applies a provider webhook.</summary>
public static class ProcessPaymentWebhook
{
    /// <summary>The command carrying the raw delivery.</summary>
    public sealed record UseCase(
        PaymentProvider Provider,
        string RawBody,
        IReadOnlyDictionary<string, string> Headers) : ICommand<bool>;

    /// <summary>Validates the command.</summary>
    public sealed class UseCaseValidator : AbstractValidator<UseCase>
    {
        /// <summary>Creates the validator.</summary>
        public UseCaseValidator() => RuleFor(command => command.RawBody).NotEmpty();
    }

    /// <summary>Handles the command.</summary>
    public sealed class UseCaseHandler(
        IPaymentGatewayRegistry registry,
        IEventSourcedRepository<Payment, Guid> repository,
        IPaymentReferenceStore references,
        IWebhookEventStore webhookStore,
        IMediator mediator) : ICommandHandler<UseCase, bool>
    {
        /// <inheritdoc />
        public async Task<Result<bool>> Handle(UseCase command, CancellationToken cancellationToken)
        {
            Result<IPaymentGateway> resolved = registry.Resolve(command.Provider);
            if (resolved.IsFailure)
                return Result<bool>.Fail(resolved.Errors);

            Result<Maybe<PaymentProviderEvent>> parsed = await resolved.Value.ParseWebhookAsync(
                command.RawBody, command.Headers, cancellationToken);

            if (parsed.IsFailure)
                return Result<bool>.Fail(parsed.Errors);

            if (parsed.Value.HasNoValue)
                return Result<bool>.Success(false);

            PaymentMetrics.WebhooksReceived.Add(1);
            PaymentProviderEvent providerEvent = parsed.Value.Value;
            string providerName = command.Provider.ToString().ToLowerInvariant();

            Result<bool> recorded = await webhookStore.TryRecordAsync(
                providerName, providerEvent.EventId, providerEvent.Type.ToString(),
                command.RawBody, cancellationToken);

            if (recorded.IsFailure || !recorded.Value)
            {
                PaymentMetrics.WebhooksDuplicate.Add(1);
                return Result<bool>.Success(false);
            }

            // Handle: a mismatched amount is audited, acknowledged, and never settled;
            // retrying the provider would not change the payload.
            if (providerEvent.Amount is { } observed)
            {
                Guid? paymentId = await references.FindAsync(
                    command.Provider, providerEvent.ProviderReference, cancellationToken);

                if (paymentId is not null)
                {
                    Result<Payment> payment = await repository.LoadAsync(paymentId.Value, cancellationToken);

                    if (payment.IsSuccess
                        && (observed.Currency != payment.Value.Amount.Currency
                            || observed.Amount > payment.Value.Amount.Amount))
                    {
                        PaymentMetrics.WebhooksMismatch.Add(1);

                        await webhookStore.MarkProcessedAsync(
                            providerName,
                            providerEvent.EventId,
                            PaymentsOutcome.Codes.WebhookAmountMismatch,
                            cancellationToken);

                        return Result<bool>.Success(false);
                    }
                }
            }

            Result<PaymentResponseModel> settled = await mediator.Send(
                new SettlePayment.UseCase(
                    command.Provider,
                    providerEvent.ProviderReference,
                    providerEvent.Type,
                    providerEvent.Amount,
                    null,
                    providerEvent.EventId),
                cancellationToken);

            await webhookStore.MarkProcessedAsync(
                providerName,
                providerEvent.EventId,
                settled.IsFailure ? PaymentConstant.Outcomes.Failed : PaymentConstant.Outcomes.Settled,
                cancellationToken);

            return settled.IsFailure
                ? Result<bool>.Fail(settled.Errors)
                : Result<bool>.Success(true);
        }
    }
}
```

```csharp
using System.Text;

using Application.Modules.Payments.Webhooks.Commands;

using Carter;

using Core.BuildingBlocks.Functional.Errors;
using Core.BuildingBlocks.Functional.Results;
using Core.Modules.Payments;

using Infrastructure.BuildingBlocks.Adapters.Serialization;

using MediatR;

using Microsoft.AspNetCore.Mvc;

namespace Web.Api.Endpoints.Payments;

/// <summary>Carter module for provider webhooks; anonymous, signature-verified.</summary>
public sealed class PaymentWebhookEndpoint : ICarterModule
{
    private const string BasePath = "/api/payments/webhooks";
    private const int MaxBytes = PaymentConstant.Defaults.WebhookMaxBytes;

    /// <inheritdoc />
    public void AddRoutes(IEndpointRouteBuilder app)
    {
        app.MapPost($"{BasePath}/{{provider}}", HandleAsync)
            .WithTags("Payments Webhooks")
            .WithName("PaymentWebhook")
            .WithSummary("Receive a signed provider webhook.")
            .AllowAnonymous();
    }

    private static async Task<IResult> HandleAsync(
        string provider,
        HttpRequest request,
        IMediator mediator,
        CancellationToken cancellationToken)
    {
        if (!Enum.TryParse(provider, ignoreCase: true, out PaymentProvider parsed))
            return Result.Fail(PaymentsOutcome.Failure.WebhookProviderUnsupported(provider)).ToApiResult();

        if (request.ContentType is null
            || !request.ContentType.StartsWith(PaymentConstant.ContentTypes.Json, StringComparison.OrdinalIgnoreCase))
            return Result.Fail(PaymentsOutcome.Failure.WebhookContentTypeUnsupported()).ToApiResult();

        if (request.ContentLength is > MaxBytes)
            return Result.Fail(PaymentsOutcome.Failure.WebhookPayloadTooLarge()).ToApiResult();

        using var reader = new StreamReader(request.Body, Encoding.UTF8);
        string rawBody = await reader.ReadToEndAsync(cancellationToken);

        IReadOnlyDictionary<string, string> headers = request.Headers
            .ToDictionary(header => header.Key, header => header.Value.ToString());

        Result<bool> result = await mediator.Send(
            new ProcessPaymentWebhook.UseCase(parsed, rawBody, headers),
            cancellationToken);

        if (result.IsFailure)
        {
            Error error = result.Errors[0];

            if (error.Code == PaymentsOutcome.Codes.WebhookSignatureInvalid)
                return Result.Fail(error).ToApiResult();

            if (error.Code == PaymentsOutcome.Codes.NotFound)
                return Result.Success().ToApiResult();
        }

        return (result.IsFailure ? Result.Fail(result.Errors) : Result.Success()).ToApiResult();
    }
}
```

```csharp
using System.Globalization;

using Core.BuildingBlocks.Domain.ValueObjects.Money;

namespace Infrastructure.Modules.Payments.Adapters.Shared;

/// <summary>Converts domain money to provider units.</summary>
public static class MoneyConverter
{
    private static readonly HashSet<string> ZeroDecimal =
        ["JPY", "KRW", "VND", "CLP", "ISK", "HUF", "TWD"];

    private static readonly HashSet<string> ThreeDecimal = ["BHD", "JOD", "KWD", "OMR", "TND"];

    /// <summary>Returns the currency exponent.</summary>
    public static int Exponent(string currency)
        => ZeroDecimal.Contains(currency) ? 0 : ThreeDecimal.Contains(currency) ? 3 : 2;

    /// <summary>Converts to the provider's minor units.</summary>
    public static Result<long> ToMinorUnits(Money money)
    {
        int exponent = Exponent(money.Currency.Code ?? "USD");
        decimal scaled = money.Amount * (decimal)Math.Pow(10, exponent);

        if (scaled != decimal.Truncate(scaled))
            return Result<long>.Fail(PaymentsOutcome.Failure.AmountInvalid(
                $"the currency allows {exponent} decimal places"));

        return Result<long>.Success((long)scaled);
    }

    /// <summary>Converts from the provider's minor units.</summary>
    public static Money FromMinorUnits(long amount, Currency currency)
        => new(amount / (decimal)Math.Pow(10, Exponent(currency.Code ?? "USD")), currency);

    /// <summary>Formats an amount for PayPal's decimal-string API.</summary>
    public static string ToDecimalString(Money money)
        => money.Amount.ToString($"F{Exponent(money.Currency.Code ?? "USD")}", CultureInfo.InvariantCulture);
}
```

```csharp
using Application.Modules.Payments.Ports;
using Application.Modules.Payments.Ports.Models;

using Core.BuildingBlocks.Functional.Maybes;
using Core.Modules.Payments;
using Core.Modules.Payments.Intents;

using Infrastructure.Modules.Payments.Adapters.Shared;

using Stripe;

namespace Infrastructure.Modules.Payments.Adapters.Stripe;

/// <summary>Stripe adapter built on Stripe.net.</summary>
public sealed class StripePaymentGateway(StripeOptions options)
    : IPaymentGateway, ISupportsPartialRefund, ISupportsManualCapture
{
    /// <inheritdoc />
    public PaymentProvider Provider => PaymentProvider.Stripe;

    /// <inheritdoc />
    public async Task<Result<PaymentIntentResult>> CreateIntentAsync(
        PaymentIntentRequest request,
        CancellationToken cancellationToken)
    {
        Result<long> minor = MoneyConverter.ToMinorUnits(request.Amount);
        if (minor.IsFailure)
            return Result<PaymentIntentResult>.Fail(minor.Errors);

        var service = new PaymentIntentService(new StripeClient(options.SecretKey));

        PaymentIntent intent = await service.CreateAsync(
            new PaymentIntentCreateOptions
            {
                Amount = minor.Value,
                Currency = request.Amount.Currency.Code!.ToLowerInvariant(),
                CaptureMethod = request.CaptureMode is PaymentCaptureMode.Manual ? "manual" : "automatic",
                AutomaticPaymentMethods = new PaymentIntentAutomaticPaymentMethodsOptions { Enabled = true },
                Metadata = new Dictionary<string, string>(request.Metadata)
                {
                    ["payment_id"] = request.PaymentId.ToString("N"),
                    ["external_reference"] = request.ExternalReference
                }
            },
            new RequestOptions { IdempotencyKey = request.IdempotencyKey },
            cancellationToken);

        return Result<PaymentIntentResult>.Success(Map(intent));
    }

    /// <inheritdoc />
    public async Task<Result<PaymentIntentResult>> RetrieveAsync(string providerReference, CancellationToken cancellationToken)
    {
        var service = new PaymentIntentService(new StripeClient(options.SecretKey));
        PaymentIntent intent = await service.GetAsync(providerReference, cancellationToken: cancellationToken);
        return Result<PaymentIntentResult>.Success(Map(intent));
    }

    /// <inheritdoc />
    public async Task<Result<PaymentCaptureResult>> CaptureAsync(
        PaymentCaptureRequest request,
        CancellationToken cancellationToken)
    {
        Result<long> minor = MoneyConverter.ToMinorUnits(request.Amount);
        if (minor.IsFailure)
            return Result<PaymentCaptureResult>.Fail(minor.Errors);

        var service = new PaymentIntentService(new StripeClient(options.SecretKey));
        PaymentIntent intent = await service.CaptureAsync(
            request.ProviderReference,
            new PaymentIntentCaptureOptions { AmountToCapture = minor.Value },
            new RequestOptions { IdempotencyKey = request.IdempotencyKey },
            cancellationToken);

        return Result<PaymentCaptureResult>.Success(
            new PaymentCaptureResult(intent.Id, request.Amount, true, null));
    }

    /// <inheritdoc />
    public async Task<Result<PaymentCancelResult>> CancelAsync(
        PaymentCancelRequest request,
        CancellationToken cancellationToken)
    {
        var service = new PaymentIntentService(new StripeClient(options.SecretKey));
        await service.CancelAsync(
            request.ProviderReference,
            new PaymentIntentCancelOptions(),
            new RequestOptions { IdempotencyKey = request.IdempotencyKey },
            cancellationToken);

        return Result<PaymentCancelResult>.Success(new PaymentCancelResult(true, null));
    }

    /// <inheritdoc />
    public async Task<Result<PaymentRefundResult>> RefundAsync(
        PaymentRefundRequest request,
        CancellationToken cancellationToken)
    {
        Result<long> minor = MoneyConverter.ToMinorUnits(request.Amount);
        if (minor.IsFailure)
            return Result<PaymentRefundResult>.Fail(minor.Errors);

        var service = new RefundService(new StripeClient(options.SecretKey));
        Refund refund = await service.CreateAsync(
            new RefundCreateOptions { PaymentIntent = request.ProviderReference, Amount = minor.Value },
            new RequestOptions { IdempotencyKey = request.IdempotencyKey },
            cancellationToken);

        return Result<PaymentRefundResult>.Success(
            new PaymentRefundResult(refund.Id, request.Amount, true, null));
    }

    /// <inheritdoc />
    public Task<Result<Maybe<PaymentProviderEvent>>> ParseWebhookAsync(
        string rawBody,
        IReadOnlyDictionary<string, string> headers,
        CancellationToken cancellationToken)
    {
        if (!headers.TryGetValue(PaymentConstant.Headers.StripeSignature, out string? signature))
            return Task.FromResult(Result<Maybe<PaymentProviderEvent>>.Fail(
                PaymentsOutcome.Failure.WebhookSignatureInvalid()));

        try
        {
            Event stripeEvent = EventUtility.ConstructEvent(
                rawBody, signature, options.WebhookSecret, throwOnApiVersionMismatch: false);

            PaymentProviderEventType? type = stripeEvent.Type switch
            {
                "payment_intent.amount_capturable_updated" => PaymentProviderEventType.Authorized,
                "payment_intent.succeeded" => PaymentProviderEventType.Captured,
                "payment_intent.payment_failed" => PaymentProviderEventType.Failed,
                "payment_intent.canceled" => PaymentProviderEventType.Cancelled,
                "charge.refunded" => PaymentProviderEventType.Refunded,
                "charge.refund.updated" => PaymentProviderEventType.RefundFailed,
                _ => null
            };

            if (type is null)
                return Task.FromResult(Result<Maybe<PaymentProviderEvent>>.Success(
                    Maybe<PaymentProviderEvent>.Empty()));

            var intent = stripeEvent.Data.Object as PaymentIntent;
            return Task.FromResult(Result<Maybe<PaymentProviderEvent>>.Success(
                Maybe<PaymentProviderEvent>.From(new PaymentProviderEvent(
                stripeEvent.Id,
                type.Value,
                intent?.Id ?? string.Empty,
                null,
                    intent is null ? null : MoneyConverter.FromMinorUnits(intent.Amount, new Currency(intent.Currency)),
                    stripeEvent.Created))));
        }
        catch (StripeException)
        {
            return Task.FromResult(Result<Maybe<PaymentProviderEvent>>.Fail(
                PaymentsOutcome.Failure.WebhookSignatureInvalid()));
        }
    }

    private static PaymentIntentResult Map(PaymentIntent intent)
    {
        PaymentProviderIntentStatus status = intent.Status switch
        {
            "requires_action" or "requires_confirmation" or "requires_payment_method" => PaymentProviderIntentStatus.RequiresAction,
            "processing" => PaymentProviderIntentStatus.Processing,
            "requires_capture" => PaymentProviderIntentStatus.Authorized,
            "succeeded" => PaymentProviderIntentStatus.Captured,
            "canceled" => PaymentProviderIntentStatus.Cancelled,
            _ => PaymentProviderIntentStatus.Failed
        };

        return new PaymentIntentResult(
            intent.Id, status, null, intent.ClientSecret, null, intent.LastPaymentError?.Code);
    }
}
```

```csharp
using System.Net.Http.Headers;
using System.Net.Http.Json;
using System.Text;

namespace Infrastructure.Modules.Payments.Adapters.PayPal;

/// <summary>Caches PayPal OAuth tokens.</summary>
public sealed class PayPalTokenProvider(HttpClient client, PayPalOptions options)
{
    private string? _token;
    private DateTimeOffset _expiresAt;

    /// <summary>Returns a valid bearer token.</summary>
    public async Task<string> GetAsync(CancellationToken cancellationToken)
    {
        if (_token is not null && _expiresAt > DateTimeOffset.UtcNow.AddMinutes(1))
            return _token;

        using var request = new HttpRequestMessage(HttpMethod.Post, "v1/oauth2/token")
        {
            Content = new StringContent("grant_type=client_credentials", Encoding.UTF8, "application/x-www-form-urlencoded")
        };
        request.Headers.Authorization = new AuthenticationHeaderValue(
            "Basic", Convert.ToBase64String(Encoding.UTF8.GetBytes($"{options.ClientId}:{options.ClientSecret}")));

        using HttpResponseMessage response = await client.SendAsync(request, cancellationToken);
        response.EnsureSuccessStatusCode();

        TokenResponse? token = await response.Content.ReadFromJsonAsync<TokenResponse>(cancellationToken);
        _token = token?.AccessToken ?? throw new InvalidOperationException("PayPal returned no access token.");
        _expiresAt = DateTimeOffset.UtcNow.AddSeconds(token.ExpiresIn);

        return _token;
    }

    private sealed record TokenResponse(
        [property: System.Text.Json.Serialization.JsonPropertyName("access_token")] string AccessToken,
        [property: System.Text.Json.Serialization.JsonPropertyName("expires_in")] int ExpiresIn);
}
```

```csharp
using System.Net.Http.Json;
using System.Text.Json;

using Application.Modules.Payments.Ports;

using Core.BuildingBlocks.Functional.Maybes;

/// <summary>PayPal Orders v2 adapter (partial refunds unsupported).</summary>
public sealed class PayPalPaymentGateway(HttpClient client, PayPalTokenProvider tokens, PayPalOptions options)
    : IPaymentGateway, ISupportsManualCapture
{
    /// <inheritdoc />
    public PaymentProvider Provider => PaymentProvider.PayPal;

    /// <inheritdoc />
    public async Task<Result<PaymentIntentResult>> CreateIntentAsync(
        PaymentIntentRequest request,
        CancellationToken cancellationToken)
    {
        using var message = new HttpRequestMessage(HttpMethod.Post, "v2/checkout/orders")
        {
            Content = JsonContent.Create(new
            {
                intent = request.CaptureMode is PaymentCaptureMode.Manual ? "AUTHORIZE" : "CAPTURE",
                purchase_units = new[]
                {
                    new { amount = new { currency_code = request.Amount.Currency.Code, value = MoneyConverter.ToDecimalString(request.Amount) },
                          custom_id = request.ExternalReference }
                }
            })
        };
        message.Headers.Authorization = new AuthenticationHeaderValue("Bearer", await tokens.GetAsync(cancellationToken));
        message.Headers.Add("PayPal-Request-Id", request.IdempotencyKey);

        using HttpResponseMessage response = await client.SendAsync(message, cancellationToken);
        if (!response.IsSuccessStatusCode)
            return Result<PaymentIntentResult>.Fail(
                PaymentsOutcome.Failure.ProviderRequestRejected(PaymentProvider.PayPal));

        using JsonDocument body = JsonDocument.Parse(await response.Content.ReadAsStringAsync(cancellationToken));
        string id = body.RootElement.GetProperty("id").GetString()!;
        string? approve = body.RootElement.GetProperty("links").EnumerateArray()
            .FirstOrDefault(link => link.GetProperty("rel").GetString() == "approve")
            .GetProperty("href").GetString();

        return Result<PaymentIntentResult>.Success(new PaymentIntentResult(
            id, PaymentProviderIntentStatus.RequiresAction, approve, null, null, null));
    }

    /// <inheritdoc />
    public async Task<Result<PaymentIntentResult>> RetrieveAsync(string providerReference, CancellationToken cancellationToken)
    {
        using var message = new HttpRequestMessage(HttpMethod.Get, $"v2/checkout/orders/{providerReference}");
        message.Headers.Authorization = new AuthenticationHeaderValue("Bearer", await tokens.GetAsync(cancellationToken));

        using HttpResponseMessage response = await client.SendAsync(message, cancellationToken);
        if (!response.IsSuccessStatusCode)
            return Result<PaymentIntentResult>.Fail(
                PaymentsOutcome.Failure.ProviderRequestRejected(PaymentProvider.PayPal));

        using JsonDocument body = JsonDocument.Parse(await response.Content.ReadAsStringAsync(cancellationToken));
        string status = body.RootElement.GetProperty("status").GetString() ?? "UNKNOWN";

        PaymentProviderIntentStatus mapped = status switch
        {
            "COMPLETED" => PaymentProviderIntentStatus.Captured,
            "APPROVED" => PaymentProviderIntentStatus.Authorized,
            "CREATED" => PaymentProviderIntentStatus.RequiresAction,
            _ => PaymentProviderIntentStatus.Failed
        };

        return Result<PaymentIntentResult>.Success(new PaymentIntentResult(
            providerReference, mapped, null, null, null, null));
    }

    /// <inheritdoc />
    public async Task<Result<PaymentCaptureResult>> CaptureAsync(
        PaymentCaptureRequest request,
        CancellationToken cancellationToken)
    {
        using var message = new HttpRequestMessage(HttpMethod.Post, $"v2/checkout/orders/{request.ProviderReference}/capture")
        {
            Content = JsonContent.Create(new
            {
                payment_source = new { },
                amount = new { value = MoneyConverter.ToDecimalString(request.Amount), currency_code = request.Amount.Currency.Code }
            })
        };
        message.Headers.Authorization = new AuthenticationHeaderValue("Bearer", await tokens.GetAsync(cancellationToken));
        message.Headers.Add("PayPal-Request-Id", request.IdempotencyKey);

        using HttpResponseMessage response = await client.SendAsync(message, cancellationToken);
        return response.IsSuccessStatusCode
            ? Result<PaymentCaptureResult>.Success(new PaymentCaptureResult(request.ProviderReference, request.Amount, true, null))
            : Result<PaymentCaptureResult>.Success(new PaymentCaptureResult(request.ProviderReference, request.Amount, false, "paypal_capture_failed"));
    }

    /// <inheritdoc />
    public async Task<Result<PaymentCancelResult>> CancelAsync(
        PaymentCancelRequest request,
        CancellationToken cancellationToken)
    {
        using var message = new HttpRequestMessage(HttpMethod.Post, $"v2/checkout/orders/{request.ProviderReference}/cancel");
        message.Headers.Authorization = new AuthenticationHeaderValue("Bearer", await tokens.GetAsync(cancellationToken));

        using HttpResponseMessage response = await client.SendAsync(message, cancellationToken);
        return Result<PaymentCancelResult>.Success(new PaymentCancelResult(response.IsSuccessStatusCode, null));

    /// <inheritdoc />
    public Task<Result<PaymentRefundResult>> RefundAsync(
        PaymentRefundRequest request,
        CancellationToken cancellationToken)
        => Task.FromResult(Result<PaymentRefundResult>.Fail(
            PaymentsOutcome.Failure.PartialRefundUnsupported()));

    /// <inheritdoc />
    public async Task<Result<Maybe<PaymentProviderEvent>>> ParseWebhookAsync(
        string rawBody,
        IReadOnlyDictionary<string, string> headers,
        CancellationToken cancellationToken)
    {
        using var message = new HttpRequestMessage(HttpMethod.Post, "v1/notifications/verify-webhook-signature")
        {
            Content = JsonContent.Create(new
            {
                transmission_id = headers.GetValueOrDefault(PaymentConstant.Headers.PayPalTransmissionId),
                transmission_time = headers.GetValueOrDefault(PaymentConstant.Headers.PayPalTransmissionTime),
                cert_url = headers.GetValueOrDefault(PaymentConstant.Headers.PayPalCertUrl),
                auth_algo = headers.GetValueOrDefault(PaymentConstant.Headers.PayPalAuthAlgo),
                transmission_sig = headers.GetValueOrDefault(PaymentConstant.Headers.PayPalTransmissionSig),
                webhook_id = options.WebhookId,
                webhook_event = JsonDocument.Parse(rawBody).RootElement
            })
        };
        message.Headers.Authorization = new AuthenticationHeaderValue("Bearer", await tokens.GetAsync(cancellationToken));

        using HttpResponseMessage response = await client.SendAsync(message, cancellationToken);
        using JsonDocument verification = JsonDocument.Parse(await response.Content.ReadAsStringAsync(cancellationToken));

        if (!response.IsSuccessStatusCode
            || verification.RootElement.GetProperty("verification_status").GetString() != "SUCCESS")
            return Result<Maybe<PaymentProviderEvent>>.Fail(
                PaymentsOutcome.Failure.WebhookSignatureInvalid());

        Maybe<PaymentProviderEvent> normalized = JsonDocument.Parse(rawBody).RootElement.GetProperty("event_type").GetString() switch
        {
            "CHECKOUT.ORDER.APPROVED" => Maybe<PaymentProviderEvent>.From(new PaymentProviderEvent(
                JsonDocument.Parse(rawBody).RootElement.GetProperty("id").GetString()!,
                PaymentProviderEventType.Authorized,
                JsonDocument.Parse(rawBody).RootElement.GetProperty("resource").GetProperty("id").GetString()!,
                null, null, DateTimeOffset.UtcNow)),
            "PAYMENT.CAPTURE.COMPLETED" => Maybe<PaymentProviderEvent>.From(new PaymentProviderEvent(
                JsonDocument.Parse(rawBody).RootElement.GetProperty("id").GetString()!,
                PaymentProviderEventType.Captured,
                JsonDocument.Parse(rawBody).RootElement.GetProperty("resource").GetProperty("supplementary_data")
                    .GetProperty("related_ids").GetProperty("order_id").GetString()!,
                null, null, DateTimeOffset.UtcNow)),
            "PAYMENT.CAPTURE.DENIED" => Maybe<PaymentProviderEvent>.From(new PaymentProviderEvent(
                JsonDocument.Parse(rawBody).RootElement.GetProperty("id").GetString()!,
                PaymentProviderEventType.Failed,
                JsonDocument.Parse(rawBody).RootElement.GetProperty("resource").GetProperty("supplementary_data")
                    .GetProperty("related_ids").GetProperty("order_id").GetString()!,
                null, null, DateTimeOffset.UtcNow)),
            _ => Maybe<PaymentProviderEvent>.Empty()
        };

        return Result<Maybe<PaymentProviderEvent>>.Success(normalized);
    }
}
```

```csharp
using Microsoft.Extensions.Options;

namespace Infrastructure.Modules.Payments;

/// <summary>Validates the payments configuration at startup.</summary>
public sealed class PaymentsOptionsValidator(string environment) : IValidateOptions<PaymentsOptions>
{
    /// <inheritdoc />
    public ValidateOptionsResult Validate(string? name, PaymentsOptions options)
    {
        List<string> failures = [];

        if (options.Limits.MaxAmount <= 0)
            failures.Add("Payments:Limits:MaxAmount must be greater than zero.");

        if (options.IntentLifetimeSeconds is < 1 or > 86400)
            failures.Add("Payments:IntentLifetimeSeconds must be between 1 and 86400.");

        if (options.ExpiryGraceSeconds is < 0 or > 3600)
            failures.Add("Payments:ExpiryGraceSeconds must be between 0 and 3600.");

        if (options.Limits.WebhookMaxBytes is < 1024 or > 1048576)
            failures.Add("Payments:Limits:WebhookMaxBytes must be between 1024 and 1048576.");

        if (options.Providers.Fake.Enabled && environment == "Production")
            failures.Add("Payments:Providers:Fake must not be enabled in Production.");

        if (options.Providers.Stripe.Enabled
            && (string.IsNullOrWhiteSpace(options.Providers.Stripe.SecretKey)
                || string.IsNullOrWhiteSpace(options.Providers.Stripe.WebhookSecret)))
            failures.Add("Payments:Providers:Stripe requires SecretKey and WebhookSecret.");

        if (options.Providers.PayPal.Enabled
            && (string.IsNullOrWhiteSpace(options.Providers.PayPal.ClientId)
                || string.IsNullOrWhiteSpace(options.Providers.PayPal.ClientSecret)
                || string.IsNullOrWhiteSpace(options.Providers.PayPal.WebhookId)))
            failures.Add("Payments:Providers:PayPal requires ClientId, ClientSecret, and WebhookId.");

        if (!Enum.IsDefined(options.Providers.PayPal.Environment))
            failures.Add("Payments:Providers:PayPal:Environment must be Sandbox or Live.");

        if (!IsEnabled(options, options.DefaultProvider))
            failures.Add($"Payments:DefaultProvider '{options.DefaultProvider}' is not enabled.");

        return failures.Count == 0
            ? ValidateOptionsResult.Success
            : ValidateOptionsResult.Fail(failures);
    }

    private static bool IsEnabled(PaymentsOptions options, string provider) => provider switch
    {
        nameof(PaymentProvider.Fake) => options.Providers.Fake.Enabled,
        nameof(PaymentProvider.Stripe) => options.Providers.Stripe.Enabled,
        nameof(PaymentProvider.PayPal) => options.Providers.PayPal.Enabled,
        _ => false
    };
}
```

```csharp
    private static async Task<string> WaitForStatusAsync(HttpClient client, Guid id)
    {
        for (int attempt = 0; attempt < 20; attempt++)
        {
            using HttpResponseMessage read = await client.GetAsync($"/api/payments/{id}");

            if (read.IsSuccessStatusCode)
            {
                using JsonDocument document = JsonDocument.Parse(await read.Content.ReadAsStringAsync());
                string status = document.RootElement.GetProperty("value").GetProperty("status").GetString()!;

                if (status is "captured" or "refunded")
                    return status;
            }

            await Task.Delay(100);
        }

        throw new InvalidOperationException("The payment projection did not catch up in time.");
    }

    private static async Task<(Guid Id, HttpStatusCode Status)> CreatePaymentAsync(
        HttpClient client,
        string idempotencyKey,
        decimal amount,
        string externalReference)
    {
        using var request = new HttpRequestMessage(HttpMethod.Post, "/api/payments")
        {
            Content = JsonContent.Create(new
            {
                amount = new { amount, currency = "USD" },
                provider = "fake",
                externalReference,
                captureMode = "automatic"
            })
        };
        request.Headers.Add("Idempotency-Key", idempotencyKey);

        using HttpResponseMessage response = await client.SendAsync(request);
        using var document = JsonDocument.Parse(await response.Content.ReadAsStringAsync());
        Guid id = document.RootElement.GetProperty("value").GetProperty("id").GetGuid();

        return (id, response.StatusCode);
    }
```

## Self-Review

**Spec coverage:** every spec section maps to a task — domain (1–2), ports/adapters (3, 8), application slices (4), persistence (5), API surface (6), webhooks/gateway (7), configuration/observability/docs/gates (9). **Known deviations to record during execution:**
1. `SettlePayment` treats a repeated terminal webhook as success (idempotent no-op) rather than `409`.
2. Admin `GET /api/admin/payments/{id}` reuses `GetPayment` with `customerId: null`; a dedicated admin query is deferred.
3. PayPal refunds return `Payments.Refund.PartialUnsupported` for the whole slice, not only partial amounts.
4. The optional `make test.payments.sandbox` target is documented in the release note but added only if a live sandbox run is requested.
5. Two synchronous side tables (`payment_idempotency_keys`, `payment_references`) exist so create replay and provider
   callbacks do not depend on projection latency; they are written by the handlers, not by projections.
6. `T-25` (live sandbox) is the only acceptance condition without a concrete step; it remains opt-in by design.
